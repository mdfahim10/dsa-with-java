1. What is an Array?

Stores same type of elements.

Stored in contiguous memory.

Index starts from 0.

Size is fixed.


int arr[] = {10,20,30,40,50};

Time Complexity

Operation	Complexity

Access	O(1)
Search	O(n)
Insert	O(n)
Delete	O(n)

22. Kadane's Algorithm

Biggest Trick

If running sum becomes negative,

Discard it.

Because

Negative sum can never increase future answer.

Algorithm

currSum+=arr[i]

max=max(max,currSum)

if(currSum<0)

currSum=0

Time

O(n)

Space

O(1)

🎯 Final Takeaway

If you remember just these core ideas, you'll be able to reconstruct almost every array solution:

1. Traverse once → Sum, Max, Min, Search, Frequency.


2. Track two values → Second Largest.


3. Shift elements → Insert, Delete, Rotation.


4. Use two pointers → Reverse.


5. Use nested loops → Pairs, Subarrays.


6. Precompute → Prefix Sum.


7. Discard negative running sums → Kadane's Algorithm.
